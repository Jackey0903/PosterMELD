# User-specified Poster Variants With a Standard Default

PosterMELD will let users explicitly choose templates, Style Profiles, and Generative Asset settings, while falling back to a Default Standard Variant when no choice is provided. The Default Standard Variant is a landscape poster using `cluster_43_landscape`, with teaser and background Generative Assets enabled by default under Content Fidelity constraints. This keeps Poster Diversity controllable and reproducible while preserving a stable baseline for development, harness evaluation, and benchmark experiments.
